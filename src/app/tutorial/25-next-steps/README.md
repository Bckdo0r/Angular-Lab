# Lección 25 — Próximos pasos

Esta actividad es **solo de lectura**. No tiene tareas `TODO` ni solución separada.

## Cómo verla

1. Iniciá el servidor con `npm start`.
2. Abrí [Próximos pasos](http://localhost:4200/tutorial/25).
3. Revisá los recursos y entrá a las [prácticas avanzadas](http://localhost:4200/extras)
   para integrar lo aprendido.

## Archivo de consulta

`src/app/tutorial/25-next-steps/leccion.ts` contiene la página de cierre.
No hace falta editarlo para completar el tutorial. Los videos y artículos externos
son material opcional y pueden usar versiones distintas de Angular; comprobá las APIs
contra la [documentación oficial](https://angular.dev/overview) y la versión del proyecto.

La numeración del tutorial conserva el salto de 20 a 22 del material adaptado.
No hay una lección 21 local pendiente de completar.
